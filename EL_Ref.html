1. System Architecture & Overview

EnhancedLabels.dll provides a lightweight, stack-safe custom control framework in Win32 using direct class registration via RegisterClassExA. By moving from Win32 child control subclassing to an owner-drawn architecture, it completely eliminates background erasing hacks, double-ghosting artifacts, and message-chain access violations during interaction.

  • Class Names: Primary control class IW_EnhancedLabelClass and custom tooltip class IW_EnhancedTooltipClass.
  • Window Handle Types: Window handles are strictly managed as UINT to align with IWBasic type requirements and avoid compiler structure conversion conflicts.
  • Rendering Pipeline: Double-buffered GDI+ rendering pipeline leveraging offscreen memory DCs, anti-aliased text hints, GDI+ linear gradient brushes, and crisp alpha transparency.
  • Dynamic Theme Palette Engine: EL_ApplyTheme re-skins the entire control dynamically at runtime—updating header gradients, body background colors, link text, link hover fills, glow halos, bottom link bars, scrollbars, and tooltips synchronously.
  • Owner-Drawn Link Engine: Pure in-memory hit-testing (rcBounds) supporting custom typography (EL_SetLinkFont), multi-column grids, hover/press state fills, link glowing halos, direct 32-bit GDI+ PNG alpha images, and dynamic icons (HBITMAP/HICON).
  • Horizontal Link Bar Strip: Dedicated bottom/top toolbar strip pass (EL_SetLinkBarHeight) rendered via GDI+ linear brushes and bounded with native Win32 dividers.
  • Custom Owner-Drawn Tooltip System: Layered popup window (WS_EX_LAYERED) rendered at 195 Alpha (~76% opacity). Features a smart 3-second auto-hide timer that suppresses timer resets on identical hover text and instantly dismisses on mouse click.
  • Animation Engine: Snapshot-blitted quadratic deceleration (ease-out) driving collapse/expand height transitions at ~60 FPS via Win32 WM_TIMER.
  • Auto-Clamping Container Resizing: EL_Resize recalculates `maxScroll` dynamically when the control container is resized or maximized, automatically clamping `scrollOffset` back within valid bounds to prevent content offset dislocation.
  • Multi-Instance Isolation: Full instance data encapsulation via SetPropA / GetPropA allowing unlimited control instances to coexist inside the same parent window.
  • Accessibility & Keyboard Navigation: Native TAB key traversal, focused control indicator borders (DrawFocusRect), and Space/Enter key execution handlers.

3. Registration & Lifecycle APIs

Exported Function Signature / Return Description
EL_RegisterControl INT Registers both IW_EnhancedLabelClass and IW_EnhancedTooltipClass window classes with RegisterClassExA. Must be called once before control instantiation.
EL_UnregisterControl INT Unregisters both custom window classes on application shutdown.
EL_Create (hwndParent:UINT, controlID:INT) -> POINTER Instantiates the custom control over a static placeholder control ID, caching full dimensions and initializing GDI+.
EL_Destroy (ptr:POINTER) -> INT Triggers DestroyWindow and frees allocated internal memory structures and typography handles.

7. Event Model & Animation System

Interactive Event Handlers

  • WM_MOUSEMOVE: Checks mouse coordinates against container bounds, bottom link bar items, and link bounding boxes (rcBounds). Updates hover indices, swaps cursor to IDC_HAND (32649), and dispatches custom tooltip positioning via ShowCustomTooltip / HideCustomTooltip.
  • WM_LBUTTONDOWN: Instantly dismisses active tooltips via HideCustomTooltip, detects header clicks to toggle collapse, or processes link item hits with mouse capture (SetCapture).
  • WM_LBUTTONUP: Releases capture, clears press states, and dispatches a WM_COMMAND (0x0111) notification with the link's cmdID directly to the parent window.
  • WM_MOUSEWHEEL: Calculates vertical scroll adjustments, clamps to maxScroll limits, and repaints container.
  • WM_KEYDOWN: Handles keyboard accessibility (TAB navigation, Space/Enter activation, and sub-group category expansion).

Collapse / Expand Animation Loop

  1. User clicks header zone or calls EL_ToggleCollapse(ptr).
  2. Control captures an offscreen bitmap snapshot (TakeControlSnapshot) of its current visual state.
  3. isCollapsed flag toggles, and a 16ms Win32 timer (EL_TIMER_ID = 1001) starts.
  4. WM_TIMER calculates progressive height steps using proportional quadratic ease-out deceleration math:
    animStep = (targetHeight - currentHeight) / 3
  5. Control resizes dynamically via MoveWindow while blitting the cached snapshot during animation steps.
  6. Timer is killed via KillTimer upon reaching target height.

8. Quick-Start Integration Guide

To integrate EnhancedLabels.dll inside an IWBasic 2.5 application:

$INCLUDE "EnhancedLabels.inc"

$MAIN
    UINT hMainWin
    POINTER pLabel
    
    ' 1. Register DLL Window Class
    IF EL_RegisterControl() = 0 THEN END
    
    ' 2. Open Stage Window
    OPENWINDOW hMainWin, 0, 0, 480, 400, @CAPTION|@SYSMENU|@MINBOX, 0, "EnhancedLabels App", NULL
    
    ' 3. Place static placeholder (ID = 100)
    CONTROL hMainWin, @STATIC, "", 20, 20, 440, 320, 0, 100
    
    ' 4. Bind Control Instance
    pLabel = EL_Create(hMainWin, 100)
    
    IF pLabel <> NULL THEN
        ' Apply Theme & Header Title
        EL_ApplyTheme(pLabel, 0) ' 0 = Dark Slate
        EL_SetHeaderStandardLeftTitle(pLabel, "Security Controls", 0xFFFFFF, 0)
        
        ' Add Text Links
        EL_AddLink(pLabel, 1001, "Run System Diagnostic", "Executes full hardware check", 0xDDDDDD, 0x00FF00, 0x222222, 255, 1, 0, 12)
        EL_AddLink(pLabel, 1002, "View Activity Logs", "Opens local security audit log", 0xDDDDDD, 0x00FF00, 0x222222, 255, 0, 1, 12)
    ENDIF

    WAITUNTIL hMainWin = 0
    
    ' Cleanup
    IF pLabel <> NULL THEN EL_Destroy(pLabel)
    EL_UnregisterControl()
END
